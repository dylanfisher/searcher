# 0104. The app icon is an SVG, rendered when the bundle is built

- **Date:** 2026-10-25
- **Status:** accepted

## Context

Searcher.app had no icon, so the Dock and the app switcher showed the generic one. Dylan picked
the "Slant" sketch: a front-on face cut into three slanted slats, each slid up or down, on a
yellow tile. The outer slats are white fading slightly toward the bottom, the middle one black
fading slightly toward the top. The bundle is put together by `scripts/bundle`, not Xcode, so
there is no asset catalog.

## Decision

`Sources/Searcher/AppIcon.svg` is the only copy of the icon. `scripts/bundle` renders it with
`sips` at the ten sizes an `.iconset` holds, packs them with `iconutil` into
`Contents/Resources/AppIcon.icns`, and `CFBundleIconFile` in `Info.plist` names it. Both tools
ship with macOS. The render takes about 0.15 s.

The SVG draws the tile at Apple's 824 px shape on a 1024 px canvas, so the icon lines up with
other apps' icons.

## Alternatives considered

- **Check in the `.icns`.** A binary that has to be regenerated by hand whenever the SVG changes,
  and nothing would notice when they diverged.
- **`rsvg-convert` or another renderer.** A new dependency; `sips` renders this SVG correctly,
  including the slanted clip paths.
- **An Icon Composer `.icon` file** for macOS 26's layered icons. It needs Xcode's tools to build
  and the project builds with SwiftPM alone. Worth revisiting before release if the system draws
  the flat icon on a plate.

## Consequences

Editing the icon means editing the SVG; the next `./scripts/bundle` or `./scripts/dev` picks it
up. The design sketches that led to it are not in the repo.
